# Dashboard de Gastos

HTML/JS puro, dados salvos no **localStorage** do navegador, separados por **cliente**.

## Usar
Abra `public/index.html` no navegador (sem servidor), ou:
```
npm install
npm start
```
e acesse http://localhost:3000

## Clientes
Use o seletor no topo para criar, trocar, renomear e excluir clientes. Cada cliente tem seus próprios gastos
(`gastos:dados:<id>`). Os dados ficam no navegador/dispositivo atual.
